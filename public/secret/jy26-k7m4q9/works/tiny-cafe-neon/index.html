UNDERSTAND / 構成と制作

ABOUTこの作品について

仙川TINY CAFEの店名を「TINY / CAFE」の2段に並べた壁掛けサインです。3Vの文字型COB LEDフィラメントを8文字使い、通常は静かに全点灯し、ときどき昭和から平成初期の電飾看板を参照した短い点滅演出が入ります。

HOW IT WORKS仕組み

ESP32-S3 Super Miniから8文字を個別制御し、各GPIOから150Ωを1本ずつ通してCOB LEDへ接続します。GND側は0.9mm裸銅線を共通BUSとしてまとめ、中央のESP32から抵抗が放射状に伸びる背面配線にしました。

電源はUSB-CでESP32-S3へ5V給電します。完成時の構成では単三2本から5Vを出すUSB昇圧電池ケースを背面上部へ搭載し、短いUSBケーブルで接続します。

BUILD NOTES制作の判断と試行

  1. 01

    大きな看板を作るより、文字そのものを光らせる

    判断の理由
    初期案では12VのG25型LED電球を大量に並べる大型看板や、アクリルを3層にしてCOBテープで文字を光らせる構成も検討していました。
    試行・確認
    大型電球マトリクス、アクリル多層パネル、文字型COB LEDの3方向を比較しました。
    変更
    3Vの文字型COB LEDフィラメントを採用し、T・I・N・Y・C・A・F・Eの8文字をそのまま発光部品として使いました。
    結論
    文字を別の構造で作って照らすより、文字自体が光る最小構成へ寄せました。
  2. 02

    実測して、外付けMOSFETを減らす

    判断の理由
    当初は8文字それぞれを外付けMOSFETで駆動する案を考えていました。
    試行・確認
    各文字の電流を実測し、3.3Vに150Ωを直列にした状態で約4.39〜5.31mA/文字で実用的に点灯することを確認しました。
    変更
    ESP32-S3の各GPIOから150Ωを1本ずつ通して直接駆動する構成へ変更しました。
    結論
    必要な電流を測ったうえで、部品点数を増やさず成立する回路へ簡略化しました。
  3. 03

    GPIO番号より、実物の距離を優先する

    判断の理由
    最初はGPIOをきれいな連番で揃えるつもりでしたが、背板へ実装すると配線距離と部品へのストレスが大きくなりました。
    試行・確認
    ESP32-S3を背面中央へ置き、各文字までの物理距離を見ながら配線経路を現物合わせしました。
    変更
    最終GPIOを物理距離に合わせた割り当てへ変更し、GNDは0.9mm裸銅線の共通BUS、GPIO側は150Ω抵抗を放射状に配置しました。
    結論
    回路図上の整列より、実物で無理なく届き、背面の見え方も成立する配線を優先しました。
  4. 04

    ゲーミングLEDではなく、昔の電飾看板を調べる

    判断の理由
    8文字を個別制御できるため演出は自由でしたが、常時派手に動かすとTINY CAFEの看板らしさから離れます。
    試行・確認
    昭和から平成初期の看板用電子点滅器を調べ、「3点1滅」など当時の4回路系の点滅論理を確認しました。
    変更
    8本のGPIOは独立のまま、演出時だけT+C / I+A / N+F / Y+Eを4つの仮想回路として扱い、普段は全点灯、たまに短い電飾パターンが入る構成にしました。
    結論
    派手さより、古い看板の動き方を小さなLED文字へ移植することを演出の基準にしました。
  5. 05

    回路を見せたまま守り、タッチ電源は足さない

    判断の理由
    背面のESP32、裸銅線、抵抗脚は作品の見せ場になりましたが、搬送や壁面接触から守る必要がありました。また、完成間際にはタッチ式電源も検討しました。
    試行・確認
    透明アクリル板をスペーサーで浮かせ、露出配線へ触れない高さを確保しました。TTP223系タッチON/OFFも検討しましたが、ESP32-S3系を切るには追加回路が必要で、内部スペースと故障点が増えました。
    変更
    背面は透明アクリルで見せたまま保護し、タッチ電源は採用せずUSB接続で起動する構成にしました。
    結論
    完成間際の便利機能より、回路が見えて、壊れにくく、確実に起動することを優先しました。

DIG DEEPER / 技術と記録

TECHNICAL NOTES技術の記録

8文字をGPIOで個別制御

8文字は個別のGPIOで制御しています。8文字全点灯、PWM起動演出、電源再投入後の正常復帰を実機確認しています。

0.9mm裸銅線の共通GND BUS

背面では上段、下段、左縦幹線を0.9mm裸銅線で構成し、ESP32-S3を中央へ置いて抵抗8本が放射状に伸びる配線としています。

通常は全点灯、演出は短時間

完成版のファームウェアは、起動演出のあと全点灯に入り、通常時は45〜120秒程度の静かな全点灯を基本に、短い昭和電飾パターンをランダムに挿入します。

電源は5V USB-C

制作後の運用試験では、4000mAhのモバイルバッテリーでも長時間点灯を確認していますが、完成仕様は単三2本のUSB昇圧電池ケースです。

WIRING DETAILS / 配線の記録

WIRING DETAILS配線の記録
  • T=GPIO8 / I=GPIO9 / N=GPIO10 / Y=GPIO13 / C=GPIO7 / A=GPIO6 / F=GPIO3 / E=GPIO2。
  • 各GPIO → 150Ω → COB LED (+)、各COB LED (-) → 0.9mm裸銅線の共通GND BUS。
  • 電源はESP32-S3のUSB-Cへ5V給電。背面は透明アクリル板をスペーサーで浮かせ、ESP32、抵抗脚、裸銅線へ直接触れない構造です。

Strings-1

弾けるフォトフレーム

フォトフレームに弦を張って終わりではなく、ちゃんと張れて、触れて、鳴らせて、それでも壁に飾れるところまで削ったStrings-1。電子工作のシリーズなのに、最後は電気を使わない構成へ着地しました。

UNDERSTAND / 構成と制作

ABOUTこの作品について

発想の起点は、板と弦だけで成立するカンテレのような構造でした。フォトフレームへギター用ペグと弦を直接組み込み、額縁の形を残したまま、指ではじけば音が出るものへ変えています。

HOW IT WORKS仕組み

6本のエレキギター弦を、下側の弦通しから真鍮ブリッジを経由して上辺のロトマチックペグへ張っています。音はアンプではなく、弦と木製フレームそのものの振動で鳴ります。

弦の張力をそのまま木枠へ掛けるのではなく、裏面へ補強板を追加し、弦通し側もアルミ板で受ける構成にしています。

BUILD NOTES制作の判断と試行

  1. 01

    ギターではなく、額縁のまま弦を張る

    判断の理由
    フォトフレームへ弦を張る構想は以前からあり、板に弦を直接張るカンテレの構造が形として近いと考えました。
    試行・確認
    木製フレームへ6個のペグを現物合わせで並べ、ペグ位置と弦の通り方を確認しました。
    変更
    ネックを追加するのではなく、フレーム上辺へペグを直接取り付け、弦を斜めに張る構造へ確定しました。
    結論
    ギターを小さく作るのではなく、フォトフレームの形そのものを弦楽器として使う方向にしました。
  2. 02

    木枠だけで、6本の張力を受けない

    判断の理由
    エレキギター弦を6本張ると、木製フォトフレームだけでは反りや変形が出る可能性がありました。
    試行・確認
    ペグ取り付け後に裏面の空きと弦の力が掛かる位置を確認し、補強板を追加できる構成を検討しました。
    変更
    上辺と側面・下辺へ金属板の補強を追加し、弦通し側はアルミ板でボールエンドを受ける構成にしました。
    結論
    見た目は額縁のままでも、弦の張力は金属部材へ逃がすようにしました。
  3. 03

    LED用の部品を、弦の出口に使う

    判断の理由
    弦通し穴は、そのまま開けるだけでは木部やアルミ板の穴が見え、仕上がりも荒くなります。
    試行・確認
    手持ち部品を合わせたところ、砲弾LED用グロメットが弦を通す穴の縁として使えることが分かりました。
    変更
    下辺の弦通し穴へLED用グロメットを装着し、真鍮棒をL字に曲げたブリッジと組み合わせました。
    結論
    電子部品として使わず、穴の仕上げと弦の通り道を整える機械部品として流用しました。
  4. 04

    ピックアップを載せずに完成とする

    判断の理由
    弾ける作品ならピックアップを載せる案もあり、実際に手元のピックアップで出力確認まで行っていました。
    試行・確認
    ジャックまで含めて追加する構成も検討しましたが、配線を仕込むとフレームの見た目が大きく変わり、加工精度も必要になります。
    変更
    今回はピックアップを外し、電源もアンプ接続も不要な構成で完成させました。
    結論
    音量や電気的な出力より、壁に飾ったまま触れて鳴らせることを選びました。

DIG DEEPER / 技術と記録

TECHNICAL NOTES技術の記録

真鍮棒をブリッジとして固定

ブリッジには手持ちの真鍮棒を使い、両端をL字に曲げてフレームへ差し込み、2液エポキシで固定しています。弦はその上を通ってペグへ向かいます。

UNDERSTAND / 構成と制作

ABOUTこの作品について

シリーズの作品が増えるほど、個別の電源とケーブルも増えていきました。そこで電源を隠すのではなく、分配そのものを一枚の作品として見せる方向へ切り替えました。JUNK YARDでは現在、MO-1、IM-1、volt-1へつながる5V MAINの起点として扱っています。

HOW IT WORKS仕組み

5V電源をコントロールボックスへ入れ、トグルスイッチと緑LEDを通して端子台へ送り、そこからバスバーへ分配し、各作品へはSPL-2という着脱できる接続口から出します。配線や端子を箱の中へ隠さず、電気の流れが表面で追える構成です。

BUILD NOTES制作の判断と試行

  1. 01

    電源の裏方を、作品にする

    判断の理由
    作品ごとに5V電源を用意すると、ACアダプタや配線が増え、シリーズ全体として扱いにくくなりました。
    試行・確認
    一つの電源から複数作品へ給電する方法を検討し、端子台やバスバー、接続コネクタを一枚の背板へ仮配置しました。
    変更
    給電機能を箱の中へ隠さず、端子と配線を表面へ出した配電盤として構成しました。
    結論
    便利な電源設備をシリーズの外側に置かず、PDB-1という一つの作品として組み込みました。
  2. 02

    デイジーチェーンをやめ、分配と接続を分ける

    判断の理由
    初期案ではWAGOを数珠つなぎにして電源を送る構成を考えていましたが、配線経路と接続口の役割が混ざっていました。
    試行・確認
    下部端子台、バスバー、SPL-2を使う構成を仮置きし、+とGNDをどこでまとめ、どこから各作品へ出すかを整理しました。
    変更
    入力を端子台で受け、赤と青のバスバーで電源ラインを分配し、SPL-2を各作品への接続口として並べる構成へ変更しました。
    結論
    電源を分ける場所と、作品を抜き差しする場所を分離し、表面を見ても流れを追いやすい構成にしました。
  3. 03

    SPL-2は分岐器ではなかった

    判断の理由
    当初はSPL-2を、1本の入力から2本へ分岐できる部品として想定していました。
    試行・確認
    導通を確認すると、内部は入力A→出力A、入力B→出力Bの1対1パススルーで、内部で分岐していないことが分かりました。
    変更
    SPL-2に分岐を任せるのをやめ、分配はバスバー側で行い、SPL-2は着脱用の接続口として使うことにしました。
    結論
    部品の役割を実測で切り分け、想定と違った部品も用途を変えてそのまま活かしました。
  4. 04

    接着するより、外せるようにする

    判断の理由
    SPL-2をエポキシで固定する案では、硬いレバーを操作するたびに背板から剥がす方向の力がかかりました。
    試行・確認
    ニコイチ接着したSPL-2を実際に扱い、ケーブルの抜き差しとレバー操作で固定部へ負荷がかかることを確認しました。
    変更
    背板とSPL-2の間をマジックテープによる脱着式へ変更し、単体でも位置を変えられるようにしました。
    結論
    固定強度だけでなく、展示中の交換や配線変更まで考え、外せることを完成条件にしました。

DIG DEEPER / 技術と記録

TECHNICAL NOTES技術の記録

配線色も配電盤の見た目に寄せる

入力側を赤、GNDを青、出力側の+ラインを黄色として整理しました。一般的な電子工作の赤/黒だけに寄せず、端子台や露出配線を含めて配電盤らしい見え方を作っています。

COMPO-1だけは5V MAINにつながない

COMPO-1は同じDC形状でも9V PDの独立系なので、5V MAINへ接続しません。

WIRING DETAILS / 配線の記録

WIRING DETAILS配線の記録
  • 5V電源 → コントロールボックス → F6端子台 → 下部端子台 → 赤/青バスバー → SPL-2接続口、という流れで分配します。
  • コントロールボックスはDC入力、トグルスイッチ、緑LEDをまとめた構成です。制作時の単体確認では5.46V出力、緑LED点灯、スイッチ動作を確認しています。
  • 緑LEDは970Ωの抵抗を介して点灯させ、インジケーターとして見える一方で主張しすぎない明るさへ落としました。

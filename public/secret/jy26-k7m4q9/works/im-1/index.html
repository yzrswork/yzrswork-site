UNDERSTAND / 構成と制作

ABOUTこの作品について

最初から今の形を狙っていた作品ではありません。斜めに収まったガラス板をきっかけに、当初のCCFL中心の構成をやめ、7セグ表示と光を上方向へ重ねる作品へ設計を切り替えました。

HOW IT WORKS仕組み

斜めに置いたハーフミラーと奥のミラーシートの間で、下部の7セグ表示と光を繰り返し反射させています。前面ガラスは手前を低く、奥を高くして約10度傾け、通常のインフィニティミラーとは違う上方向の連なりを作りました。

表示制御にはDigisparkを使い、TM1637の6桁7セグを駆動します。光学部分へ余計なものを映り込ませないため、内部の見え方と基板サイズを優先して構成を削っています。

BUILD NOTES制作の判断と試行

  1. 01

    斜めに入ったガラスを、設計にする

    判断の理由
    当初は通常のインフィニティミラーとして奥方向へ反射させる構成を考えていました。
    試行・確認
    別のフォトフレームのガラス板をいくつか当てていたところ、1枚がフレーム内へ斜めに収まりました。その状態でハーフミラーシートを重ねると、反射が奥ではなく上方向へ伸びることを確認しました。
    変更
    前面ガラスを約10度傾ける構造へ変更し、CCFL中心の案をやめて、下部のTM1637 6桁7セグとWS2812Bを使う構成へ刷新しました。
    結論
    偶然できた角度をそのまま作品の中心にして、数字が上へ積み重なるIM-1の構造を確定しました。
  2. 02

    余計な反射を減らすために、内側を黒くする

    判断の理由
    白や素材色の内壁が残ると、余計な反射が増えて像がぼやけると考えました。
    試行・確認
    斜めガラスを支える内枠を作りながら、反射面の周囲に何が見えるかを確認しました。
    変更
    内枠を5mmの黒いカラーボードで作り、マットな黒で内部を統一しました。
    結論
    発光部以外を目立たせず、上方向へ続く数字と光だけを拾いやすい構成にしました。
  3. 03

    Arduino Nanoを、もっと小さくする

    判断の理由
    Arduino Nanoをフレーム内へ置くと、ハーフミラーへ基板自体が映り込むことが分かりました。
    試行・確認
    TM1637の制御に必要な信号数を確認すると、DIO / CLKの2本が中心で、より小さなMCUでも成立すると判断できました。
    変更
    Arduino NanoからDigispark（ATtiny85）へ変更し、フレーム側壁へ収めました。
    結論
    制御に必要な機能は残しつつ、光学面へ映り込む基板の存在感を減らしました。
  4. 04

    三つのモードより、安定して動く二つの演出

    判断の理由
    当初は3ポジションスイッチで複数モードを切り替える計画でしたが、中間位置やINPUT_PULLUPまわりで安定した判定が得られませんでした。
    試行・確認
    2ポジションへ簡略化し、ATtiny85の入力ピンも見直してP3で動作確認。カウントダウンと横バー演出まで実機で確認しました。最終配線ではスイッチに5Vを入れた構成が動かなかったため、さらに切り分けを行いました。
    変更
    演出をカウントダウンと横バーへ絞り、完成時はP3をGNDへ固定。物理トグルはDC入力とDigisparkの5Vライン間に置くキルスイッチへ変更しました。
    結論
    モード選択を増やすより、表示が確実に立ち上がり、作品として安定して見せられる構成を選びました。

DIG DEEPER / 技術と記録

TECHNICAL NOTES技術の記録

TM1637 6桁の物理桁マッピング

使用した6桁モジュールは3桁+3桁の2チャンク構成で、setSegments()の配列順と物理的な桁位置がそのまま一致しませんでした。実機で点灯位置を確認し、チャンク単位の逆順を踏まえて表示配列を組み替えています。

WIRING DETAILS / 配線の記録

WIRING DETAILS配線の記録
  • DigisparkからTM1637へ、P0=DIO、P2=CLKで接続。
  • 試作ではP3をスイッチ入力として使用。最終配線ではP3をGNDへ固定し、トグルスイッチをDC入力とDigisparkの5Vライン間に入れるキルスイッチ構成へ変更しました。

UNDERSTAND / 構成と制作

ABOUTこの作品について

額縁の前面に表示と操作、裏側に再生回路と電源を収めました。画面、ノブ、赤い再生表示を、一つの額縁の中で使える構成です。

HOW IT WORKS仕組み

表示や操作はRP2350-Plus、音楽再生はDFPlayer Miniに任せています。全部を一つで処理せず、役割を分けた構成です。

ノブを回して曲を選び、押して再生・停止します。画面は曲の情報と表紙を切り替え、赤いLEDが再生中を知らせます。音は3.5mmステレオ端子から外部へ送ります。

BUILD NOTES制作の判断と試行

  1. 01

    額縁を決める

    試行・確認
    深型額縁に部品を仮置きし、基板やコネクタの配置と、裏側へ通す配線の経路を検討しました。
    変更
    深型額縁をマットブラックに塗装し、表示基板は前面、DFPlayer Miniと電源は裏面へ分けました。
  2. 02

    再生表示を赤にする

    判断の理由
    当初の青いLEDは、3.3V駆動では順方向電圧が高く、点灯しにくいことが分かりました。
    変更
    赤い5mm LEDへ変更し、GP10から抵抗を介して点灯させました。
    結論
    再生状態を目で確認できる構成を優先しました。
  3. 03

    画像用SDをやめる

    判断の理由
    DFPlayer側のカードをRP2350と共有する構成は現実的ではなく、表紙には別の保存方法が必要でした。
    試行・確認
    別のSDカードから画像を読む案では、SPIピンの割り当てが合わず、初期化で処理が止まる問題も確認しました。
    変更
    共通の表紙画像をRP2350のフラッシュへ収め、音楽用SDカードだけを残しました。
    結論
    全曲共通の表紙1枚をフラッシュから表示する構成へ収束させ、実機で画像モードの表示を確認しました。

DIG DEEPER / 技術と記録

TECHNICAL NOTES技術の記録

日本語表示の切り分け

画面自体は描画できても日本語テキストが出ない状態を確認。U8g2のUTF-8設定を有効にして表示を復旧しました。

流用基板

DFPlayer Miniの取り付けには、流用基板を再利用。中央の軸穴はステレオ端子の取り付けに使いました。

WIRING DETAILS / 配線の記録

WIRING DETAILS配線の記録
  • DFPlayer Mini RX → RP2350 GP12、TX → GP13。2026年6月22日に実機配線とUART0の対応を確認しました。
  • DFPlayer MiniのDAC_L / DAC_R / GNDを3.5mmステレオ端子のTip / Ring / Sleeveへ接続。
  • DC入力の5V幹線に電源スイッチを置き、RP2350とDFPlayer Miniを一括でオン・オフします。

UNDERSTAND / 構成と制作

ABOUTこの作品について

出発点は、液晶表示が欠けたALBA SPOONでした。修理は断念しましたが、丸窓のケースは残したくて、手元にあった小型電圧計を中へ入れる方向へ役割を変えました。

HOW IT WORKS仕組み

腕時計の丸窓の後ろへ2線式の小型電圧計を配置し、表示面の高さをスペーサーで調整しています。ケース自体は黒アクリル板へ固定し、元の文字盤ではなく電圧表示だけが窓から見える構成です。

JUNK YARDではPDB-1の5V MAINからSPL-2を介して直接給電し、その系統の電圧を表示します。独立した時計でも単体テスターでもなく、展示全体の電源系にぶら下がる一つの計器として動きます。

BUILD NOTES制作の判断と試行

  1. 01

    修理をやめて、役割を残す

    判断の理由
    ALBA SPOONの液晶欠けを直そうと分解しましたが、修理には高い難度と部品調達が必要でした。
    試行・確認
    ムーブメントまで分解して修理方法を調べましたが、時計として元へ戻す作業はそこで断念しました。
    変更
    丸窓のケースだけを残し、手元にあった3桁の小型電圧計を収める案へ切り替えました。
    結論
    時間を測る道具を修復するのではなく、「測る」という役割だけを別の対象へ引き継ぎました。
  2. 02

    丸窓から数字が読める高さへ合わせる

    判断の理由
    電圧計をそのまま置くだけでは、腕時計の丸窓と表示位置・高さが合いませんでした。
    試行・確認
    元のガラス板と同厚の2mm黒アクリル板をマウントにし、スペーサーを現物合わせして表示面の位置を確認しました。
    変更
    ZN02BをM2ビスとホットボンドでアクリル板へ固定し、スペーサーで高さを調整。丸窓の中央から数字が読める位置へ合わせました。
    結論
    腕時計ケースを飾りとして貼るのではなく、窓そのものを表示器の開口として使いました。
  3. 03

    元のラグ穴を、そのまま固定点に使う

    判断の理由
    ケースを接着だけで貼り付けると、腕時計だった形の痕跡が弱くなります。
    試行・確認
    残っていたラグ穴を貫通加工。最初の1mmドリルは途中で折れたため、手持ちの2mmへ切り替えて加工を完了しました。
    変更
    0.6mm銅線をラグ穴へ通し、黒アクリル板へケースを縛るように固定しました。
    結論
    腕時計の構造を消さず、もともとの取り付け位置を別用途の固定点として再利用しました。
  4. 04

    単体給電から、展示の5V MAINへつなぐ

    判断の理由
    制作時は3.5mmモノラルジャックなど独立した給電口も検討していましたが、JUNK YARDではPDB-1を中心に5V系をまとめる方針へ変わりました。
    試行・確認
    展示側でMO-1、IM-1、volt-1を同じ5V MAINへ接続する構成を整理し、volt-1には独立DCジャックを持たせない方針を確認しました。
    変更
    PDB-1 → SPL-2 → 露出線でvolt-1へ直接つなぐ現在仕様へ変更しました。
    結論
    単独で5Vを表示する小物から、展示電源そのものを見せる計器へ役割を更新しました。

DIG DEEPER / 技術と記録

TECHNICAL NOTES技術の記録

2線式電圧計

使用したZN02B-V4.0は2線式で、給電されている電圧そのものを表示します。DC 4.5〜30V範囲、自己消費電流約20mAとして扱い、5V入力時に5.0X〜5.1X付近の表示を確認しています。

WIRING DETAILS / 配線の記録

WIRING DETAILS配線の記録
  • 現在の展示系統は PDB-1 5V/GND → SPL-2 → volt-1露出線。volt-1側に独立DCジャックは設けません。
  • ZN02Bは2線式のため、5V/GNDへ接続するとその供給電圧を表示します。

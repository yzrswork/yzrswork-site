UNDERSTAND / 構成と制作

ABOUTこの作品について

YS-AP50Lのアンプ基板を額縁へ収め、BluetoothまたはAUX入力で鳴らす3連ステレオスピーカー。展示に合わせて、端子の外部化、入力切替、電源を作り直しています。

BUILD NOTES制作の判断と試行

  1. 01

    端子を外へ出す

    判断の理由
    アンプ基板を額縁の中へ収めると、スピーカー端子やAUX、電源へ外からアクセスしにくくなりました。
    試行・確認
    YS-AP50LのAUX IN / OUT、外部ジャック、DC電源の極性をテスターで実測。基板パッドへ直接ハンダ付けする案も検討しました。
    変更
    基板側の既存ジャックは残し、AUXはオーディオケーブル、DCは5.5mm DCプラグを挿して外部へ延長する方式へ変更しました。
    結論
    基板を直接加工せず、着脱できる接続を残しながら、ハンダ箇所も減らす構成にしました。
  2. 02

    鳴らない原因を、出力の先へ絞る

    判断の理由
    組み上げ後、Bluetoothは接続できるのに左右のスピーカーから音が出ませんでした。
    試行・確認
    電源約5.22Vを確認し、音楽再生中のアンプ出力もL / Rともに確認。アンプまでは正常と分かり、スピーカーへ向かうモノラルジャック配線へ範囲を絞りました。
    変更
    スイッチ付きモノラルジャックのSW端子へ誤配線していた箇所を、実際の音声接点へ配線し直しました。
    結論
    配線修正後に正常再生。見た目では分からない無音を、順番に測って接続部まで追い込みました。
  3. 03

    AUXの自動検出をトグルに置き換える

    判断の理由
    展示準備でMO-1を外部AUX INへつなぐと再び無音になりました。純正AUX INへ直接挿した場合は正常に再生できました。
    試行・確認
    純正AUX INの端子を導通確認し、挿入検出の接点があることを確認。外部化で延長したのは音声3線だけで、この検出DETを再現していなかったことを特定しました。
    変更
    展示では使わないAUX OUTを撤去し、その位置へDET-GNDを切り替える物理トグルを追加しました。
    結論
    自動検出を複製せず、OFF=Bluetooth / ON=AUXをスイッチ位置で明示する構成に変更。MO-1からのAUX再生とBluetooth再生の両方を確認しました。
  4. 04

    5Vで動かすより、9Vで静かに使う

    判断の理由
    無音問題を直した後、5V動作では無音時のホワイトノイズが目立ちました。
    試行・確認
    安定化電源で5V、6V、9V、12V以上を比較。5Vでは大きく、6Vで改善し、9Vでは実用上ほぼ気にならないレベルまで下がることを確認しました。
    変更
    展示電源を5V MAINから分離し、PDモバイルバッテリーから9V PDトリガーケーブルで給電する構成へ変更しました。
    結論
    12Vまで上げなくても9Vで展示用途を満たせたため、現行仕様は9V PDとしました。

DIG DEEPER / 技術と記録

TECHNICAL NOTES技術の記録

スイッチ付きモノラルジャック

使用したジャックにはTIP / Sleeve以外に、プラグ挿抜で状態が変わるSW端子がありました。SW端子へ誤配線すると、プラグを挿した瞬間にスピーカー回路が切れる状態になります。

AUX挿入検出DET

YS-AP50Lの純正AUX INでは、プラグ挿入時だけ特定端子がGNDへ導通する挙動を実測しました。外部AUX化ではL / R / GNDだけでなく、この挿入検出も考慮する必要があります。

BTL出力と非絶縁ジャック

使用したモノラルジャックは非絶縁タイプです。今回は前面がアクリル板なので問題化しませんでしたが、金属パネルへ変更する場合は左右出力を金属経由で共通化しないよう、絶縁タイプの採用が必要です。

WIRING DETAILS / 配線の記録

WIRING DETAILS配線の記録
  • 左右スピーカーは、アンプ側のL / R出力から3.5mmモノラルジャックを介してそれぞれ接続。スイッチ付きジャックではSW端子と音声接点を区別して配線します。
  • 展示仕様の入力切替は DET → toggle → GND。トグルOFFでDET-GND非導通=Bluetooth、ONで導通=AUX。
  • 展示電源は PDモバイルバッテリー → 9V PDトリガーケーブル → YS-AP50L / COMPO-1。9V出力、駆動、低ノイズを実機確認済みです。

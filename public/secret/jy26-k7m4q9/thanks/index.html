NFC TAG / REUSEONE MORE
THING.

このNFCタグは、別のURLを書き込んで再利用できます。書き換え可能な状態のタグと、NFCに対応した端末、NFC書き込みアプリを使います。

書き換えられる状態を保つために

「READ ONLY」「LOCK」「永久書き込み保護」は選ばないでください。永久ロックすると解除できず、今後URLを書き換えられなくなる場合があります。

iPhone

NFCタグへの書き込みに対応したアプリを使います。画面名やタグをかざす位置は、端末・アプリによって異なります。

  1. NFC書き込みアプリを開きます。
  2. 書き込む内容として、URL / NDEFのURLレコードを選びます。
  3. 新しいURLを入力します。
  4. アプリの書き込み操作を開始し、案内に従ってタグを端末にかざします。
  5. 書き込み後、タグを読み取り、目的のURLが開くか確認します。

Android

NFCに対応した端末でNFCを有効にし、タグへの書き込みに対応したアプリを使います。画面名やタグをかざす位置は、端末・アプリによって異なります。

  1. NFC書き込みアプリを開きます。
  2. 書き込む内容として、URL / NDEFのURLレコードを選びます。
  3. 新しいURLを入力します。
  4. アプリの書き込み操作を開始し、案内に従ってタグを端末にかざします。
  5. 書き込み後、タグを読み取り、目的のURLが開くか確認します。

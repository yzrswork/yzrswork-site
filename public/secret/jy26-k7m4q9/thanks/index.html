NFC TAG / REUSEONE MORE
THING.

このNFCタグは、別のURLを書き込んで再利用できます。書き換えには、NFCに対応した端末と NFC Tools（wakdev） を使うと分かりやすいです。

使うアプリ

NFC Tools / wakdev の無料版でURLを書き込めます。ストアで似た名前が表示された場合も、今回のURL書き換えでは「NFC Tools」を選べばOKです。「NFC Tools - Pro Edition」「NFC Tasks」は必要ありません。

iPhone / App StoreでNFC Toolsを開く
Android / Google PlayでNFC Toolsを開く

書き換えられる状態を保つために

「READ ONLY」「LOCK」「永久書き込み保護」は選ばないでください。永久ロックすると解除できず、今後URLを書き換えられなくなる場合があります。

iPhone

NFC Toolsを開いてURLを書き込みます。アプリの言語やバージョンによって表示名が少し異なる場合があります。

  1. 「Write（書き込み）」を開きます。
  2. 「Add a record（レコードを追加）」を選びます。
  3. 「URL / URI」を選びます。
  4. 新しいURLを入力し、「Validate（確認）」を選びます。
  5. 「Write / X Bytes（書き込み）」を選び、案内に従ってタグをiPhoneにかざします。
  6. 書き込み後は「Read（読み取り）」でタグを読み、目的のURLが開くか確認します。

Android

NFCを有効にしてNFC Toolsを開き、URLを書き込みます。アプリの言語やバージョンによって表示名が少し異なる場合があります。

  1. 「Write（書き込み）」を開きます。
  2. 「Add a record（レコードを追加）」を選びます。
  3. 「URL / URI」を選びます。
  4. 新しいURLを入力し、「Validate（確認）」を選びます。
  5. 「Write / X Bytes（書き込み）」を選び、案内に従ってタグを端末にかざします。
  6. 書き込み後は「Read（読み取り）」でタグを読み、目的のURLが開くか確認します。

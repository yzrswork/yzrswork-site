弦を張ったフォトフレーム

CONCEPT / コンセプト

フォトフレームに弦を張り、飾るだけだった額縁を「触れると鳴るもの」にしました。カンテレのような、板と弦だけで成立するシンプルな弦楽器の構造から着想しています。壁に飾ったまま、ふと指ではじいて音を鳴らせる作品です。

KEY SPECS / 主要仕様

TYPE
object / sound
SIZE
164 × 207 mm
POWER
none
PARTS
wooden photo frame, electric guitar strings ×6, rotomatic tuners ×6, brass rod bridge, aluminum reinforcement plate, LED grommets

PRODUCTION MEMO / 制作メモ

木製フレームにギター用ペグを6個取り付け、真鍮棒をブリッジとして固定。下辺には弦通し穴を設け、LED用グロメットを流用して弦を通しました。弦のテンションに耐えるよう裏面をスチールとアルミ板で補強しています。当初はピックアップの搭載も検討しましたが、「飾れる・触れる」を優先して電気を使わない構成で完成させました。

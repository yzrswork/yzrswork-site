CONCEPT / コンセプト

深いフォトフレームにインフィニティミラー構造を組み込みました。ひょんなことから前面ガラスを約10度傾けたことで、反射が「奥」ではなく「上」へ無限に伸び、下部の7セグメントの数字が上方向へ積み重なっていきます。

PRODUCTION MEMO / 制作メモ

Arduino Nanoはハーフミラーに映り込むためDigispark（ATtiny85）へ変更しました。内壁を黒にして余計な乱反射を抑え、3ポジションSWのフローティング問題に詰まった結果、2ポジションの演出へ絞るようにしています。

TROUBLES / 制作トラブルと切り分け

ハーフミラーに映り込むマイコン

当初予定の Arduino Nano は、フレーム内に仮置きすると基板がハーフミラーへ映り込んだ。ほぼ切手サイズの Digispark（ATtiny85）へ変更して解消した。TM1637 の制御は DIO と CLK の2本だけなので、ピン数の少ない ATtiny85 でも問題なかった。

3ポジションスイッチのフローティング

3モード切り替えを狙った3ポジションスイッチは、中ポジションで INPUT_PULLUP が不安定になり、OFF の判定ができなかった。2ポジションのトグルスイッチへ変更し、演出も横バーがゆっくり移動する1種へ絞った。結果として、時間と無限をテーマにした静かな演出に寄った。

7セグ表示の桁順の入れ替わり

TM1637 の6桁モジュールは、基板によって物理的な桁の並びが入れ替わるものがあり、123456 と設定しても 321654 と表示されることがある。スケッチ側で表示データの並びを入れ替え、実機で確認しながら対応を確定した。

内壁の乱反射

内壁が素地のままだと余計な乱反射が増えて像がぼやけるため、内壁と内枠をマットな黒に統一した。

MEASUREMENTS / 実測

斜め配置の確定寸法

前面ガラスを約10度傾ける配置は、底辺 150mm、高さ差 26mm、斜辺 153mm で確定した。ガラス板は 102 x 153 x 2mm。内枠は5mm厚のカラーボードを平行四辺形に切って自作している。

展示給電の受け入れ試験（2026-10-04）

展示本番の給電構成（5V モバイルバッテリーから PDB-1 経由）で、MO-1 と IM-1 を3時間以上連続駆動して異常なし。volt-1 を加えた本番構成でも2から3時間運用し、cold start や電圧降下、モバイルバッテリーの auto-off まで確認した。判定は acceptance COMPLETE / PASS。

CONCEPT / コンセプト

複数の作品へ電源を配るための配電部分を、隠す裏方ではなく一枚の作品として表面実装にしました。入力されたDC電源を分岐し、スイッチ、分配端子をひとつのボード上にまとめています。JUNK YARDでは5V MAINの起点として運用です。

PRODUCTION MEMO / 制作メモ

ジャンクで手に入れた大きな端子台や、赤と青のバスバー、WAGOなど、手元にあった配電用の部品を組み合わせて作りました。機能だけなら箱の中に隠せる部分ですが、配線や端子そのものが見えるよう、一枚のボード上に並べています。

TROUBLES / 制作トラブルと切り分け

SPL-2 は分岐できなかった

WAGO SPL-2 は、1本の入力を2本へ分岐できる部品だと勘違いして進めていた。実物は入力と出力の1対1パススルーで、分岐はできない。導通を改めてチェックして気づいた。用途は接続口として便利なことに変わりないため、採用は続けた。

SPL-2 の固定方法の変更

当初は SPL-2 をエポキシで背板へ貼る計画だったが、スプリングが硬く、ケーブルを抜き差しするたびに剥離方向の力がかかり、剥がれるのが時間の問題だった。マジックテープの脱着式へ変更し、レイアウト変更と個別メンテナンスができるようになった。

展示受け入れ時の出力異常

2026-10-04 の final acceptance で、下部出力 LINE の一系統が約0.1mV しか出ていないことを確認し、配線を修復した。

MEASUREMENTS / 実測

完成時の電圧と LED の調整

完成時の電圧計の表示は 5.58V。緑 LED は、通常の150オーム前後では展示空間で眩しすぎるため、抵抗を970オームにして電流を約5mAまで絞り、ぼんやり光る程度に調整した。

受け入れ試験（2026-10-04）

配線の修復後、PDB-1 から MO-1 と IM-1 へ給電して3時間以上連続駆動し、異常なし。volt-1 を加えた本番構成でも2から3時間運用し、判定は acceptance COMPLETE / PASS。

EXHIBITION / 展示

JUNK YARD（2026-10-11 から 10-25、仙川 TINY CAFE）の最終展示9点の1つ。会期中は 5V MAIN の起点として、モバイルバッテリーから MO-1、IM-1、volt-1 へ給電した。作品紹介は 2026-10-02 に投稿された。

JUNK YARD 2026 / WORK PDB-1

PDB-1

配電盤

CONCEPT / コンセプト

複数の作品へ電源を配るための配電部分を、隠す裏方ではなく一枚の作品として表面実装にしました。入力されたDC電源を分岐し、スイッチ、分配端子をひとつのボード上にまとめています。JUNK YARDでは5V MAINの起点として運用です。

KEY SPECS / 主要仕様

TYPE
power
SIZE
180 × 238 mm
POWER
DC power distribution / exhibition source: 5V MAIN
PARTS
WAGO SPL-2, red / blue busbar terminal blocks, control box, toggle switch, green LED

PRODUCTION MEMO / 制作メモ

ジャンクで手に入れた大きな端子台や、赤と青のバスバー、WAGOなど、手元にあった配電用の部品を組み合わせて作りました。機能だけなら箱の中に隠せる部分ですが、配線や端子そのものが見えるよう、一枚のボード上に並べています。

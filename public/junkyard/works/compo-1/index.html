COMPO-1

3連ステレオスピーカーシステム

CONCEPT / コンセプト

MO-1を眺めていて、アンプとスピーカーを別に足すなら、ただの付属品ではなく昔のコンポのように「3つで一組」にしたら面白いと思ったのが出発点。同じ深型額縁3個をL / AMP / Rに分け、並べたり積んだり飾れるコンポみたいにしてみました。

KEY SPECS / 主要仕様

TYPE
sound
SIZE
108 × 146 mm each / 3-piece
POWER
9V+ recommended / DC 5.5×2.1mm center positive
PARTS
YS-AP50L, 40mm 8Ω speaker ×2, Seria deep photo frame ×3, 2–3mm acrylic front panels, mono mini jacks, rubber washers

PRODUCTION MEMO / 制作メモ

組み上げ後、Bluetoothには接続できるのに音が出ないトラブルが発生。原因はスイッチ付きモノラルジャックのスイッチ端子への誤配線だった。正しいTIP / Sleeve端子へ配線し直して音出しに成功した後、5Vではホワイトノイズが目立つことも判明。6V、9V、12Vで実測比較し、9V以上での運用を推奨している。

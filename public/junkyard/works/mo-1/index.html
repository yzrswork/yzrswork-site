Music Organizer

CONCEPT / コンセプト

何にしようかと悩んだ末、「Music Organizer」にしようと思ったのが出発点。ストリーミングで無限に音楽を聴ける時代だからこそ、あえて選んだ曲だけを収めた、小さな閉じたプレーヤーを作りました。たまに戻ってきて音楽を聴く、“心のJuke Joint”のような一台。

PRODUCTION MEMO / 制作メモ

当初のゴールド×赤マットのL判フレーム案から、黒く塗装した深型額縁へ変更。DFPlayer Miniはaitendoのポリバリコン取付基板をキャリアとして再活用しました。3.3VではVfの高い青LEDが点灯しにくいため、再生表示は赤い5mm LEDへ変更しています。

TROUBLES / 制作トラブルと切り分け

青い LED が点かない

再生表示の LED を青にしたかったが、マイコンの GPIO へ直結しても光らなかった。青 LED の順方向電圧は約3.0から3.4V で、GPIO の 3.3V では足りない。赤 LED は約2.0V で足りるため、赤い5mm LED へ変更した。

画面が真っ暗になる問題を2回に分けて切り分け

SPI ライブラリを変えたら画面が真っ暗になった件は、その方式が GP0 と GP1 では動作しないことが原因で、動作実績のある SWSPI へ戻して解消した。図形は出るのに日本語文字だけ描画されない件は、U8g2 フォントを使う場合に setUTF8Print(true) の呼び出しが必須だったことが原因。色つき四角のマーカーを初期化のステップごとに置く方法で、シリアルが繋がらない状況でも画面だけで停止箇所を特定できた。

SD.begin() がハングする

SD の初期化は、失敗を返すのではなく無限待ちになった。SPI のピン指定とコントローラの組み合わせが合っていなかったためで、最終的には画像用 SD 自体を廃止し、表紙画像をマイコンのフラッシュ内蔵へ移した。SD は音楽カード1枚だけになった。

展示現場の AUX ノイズ（未解決）

設営時、モバイルバッテリー1台の2出力を同時利用し、COMPO-1 の AUX 入力へ接続したときに強いホワイトノイズを確認した。COMPO-1 の Bluetooth 再生では出ないことまでは切り分けたが、共有電源やアナログ音声の GND 経路などの候補から原因を確定するには至っていない。会期中は電源を2台に分けて運用したが、解消したかどうかの確認は取れていない。

MEASUREMENTS / 実測

裏配線の通し穴の実測（2026-06-22）

アクリル板に開けた直径3mm の穴5つの位置を、ボリュームダイヤル脇の基準穴から実測した。GP13 は14mm、GP12 は17mm、GND は25mm。2.54mm ピッチの理論値との差はどちらも約+0.4mm で揃い、基準の取り方による系統的なオフセットと判断して、そのまま採用した。

本番コンテンツと給電の受け入れ（2026-10-04）

展示本番用の13曲を投入し、実機再生の acceptance を PASS した。給電系は PDB-1 経由の 5V MAIN で、本番構成を2から3時間運用して異常なし。

EXHIBITION / 展示

JUNK YARD（2026-10-11 から 10-25、仙川 TINY CAFE）の最終展示9点の1つ。作品紹介の第1弾として 2026-09-28 に紹介投稿された。会期中は 5V MAIN から給電し、音声は COMPO-1 の AUX 入力へ接続して使われた。会期全体を通して、安全固定と動作はまったく問題なし（オーナー報告）。

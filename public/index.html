03困りごとから探すProblem index

道具の名前ではなく、
いま困っていることから。

計算機、早見表、診断ナビ。作業台でそのまま使える代表的な9つの道具です。

分野を選ぶと、困りごとと道具の一覧が開きます。

電子工作

3つの道具
TOOL 01 ／ CALCULATE

LEDの抵抗値や電池の持ち時間を計算したい

LED抵抗、オームの法則、カラーコード、555、電池駆動時間をまとめて確認。

計算する　→
TOOL 02 ／ WIRING

部品の端子や極性が分からない

ジャック、スイッチ、LEDなどの端子と極性を色分け。テスターでの確認方法も。

端子を確認する　→
TOOL 03 ／ SOLDERING

はんだ付けの温度や条件を確認したい

こて先温度、作業条件、うまく付かないときの確認ポイントを整理。

はんだ付けを確認する　→

自作PC

4つの道具
TOOL 04 ／ PC BUILD

自作PCの構成と電源容量を整理したい

CPU、メモリ、GPU、ストレージを整理しながら、電源容量の目安まで確認。

PC構成を組む　→
TOOL 05 ／ USB-C

このUSB-Cケーブルで何ができるか知りたい

充電W数、転送速度、映像出力から、手持ちケーブルの能力と必要仕様を切り分け。

USB-Cを見分ける　→
TOOL 06 ／ HARD DRIVE

HDDの用途やCMR・SMRを確認したい

WDシリーズなどのHDDを、用途や記録方式から選ぶ条件を整理。

HDDを確認する　→
TOOL 07 ／ MEMORY

PCメモリの世代や容量を整理したい

DDR世代、容量、用途から、自作PCに必要な条件を確認。

メモリを確認する　→

DIY・模型

2つの道具
TOOL 08 ／ ADHESIVE

この素材同士を何でくっつけるか迷った

素材を2つ選び、接着剤の種類と注意点を確認。素材の見分け方にも対応。

接着剤を選ぶ　→
TOOL 09 ／ PAINT

今日はDIY塗装できる日か知りたい

気温、湿度、露点、降水、風から、DIY塗装ができるタイミングか確認。

今日塗れるか調べる　→

や印工務店は、電子工作、自作PC、DIY・模型の制作や修理で必要になった道具と記録をまとめている個人の工房です。一度調べたことを、計算機や診断ナビ、早見表として少しずつ道具にしています。うまくいかなかった方法も、次の判断に使える情報として残します。

運営者情報、お問い合わせ、利用上の注意やプライバシーは工房案内にまとめています。

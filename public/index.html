03困りごとから探すProblem index

いま困っていることから。

分野を選ぶと、困りごとと道具の一覧が開きます。

電子工作

3つの道具
TOOL 01 ／ CALCULATE

LEDの抵抗値や電池の持ち時間を計算したい

LED抵抗、オームの法則、カラーコード、555、電池駆動時間をまとめて確認。

計算する　→
TOOL 02 ／ WIRING

部品の端子や極性が分からない

ジャック、スイッチ、LEDなどの端子と極性を色分け。テスターでの確認方法も。

端子を確認する　→
TOOL 03 ／ SOLDERING

はんだ付けの温度や条件を確認したい

こて先温度、作業条件、うまく付かないときの確認ポイントを整理。

はんだ付けを確認する　→

自作PC

4つの道具
TOOL 04 ／ PC BUILD

自作PCの構成と電源容量を整理したい

CPU、メモリ、GPU、ストレージを整理しながら、電源容量の目安まで確認。

PC構成を組む　→
TOOL 05 ／ USB-C

このUSB-Cケーブルで何ができるか知りたい

充電W数、転送速度、映像出力から、手持ちケーブルの能力と必要仕様を切り分け。

USB-Cを見分ける　→
TOOL 06 ／ HARD DRIVE

HDDの用途やCMR・SMRを確認したい

WDシリーズなどのHDDを、用途や記録方式から選ぶ条件を整理。

HDDを確認する　→
TOOL 07 ／ MEMORY

PCメモリの世代や容量を整理したい

DDR世代、容量、用途から、自作PCに必要な条件を確認。

メモリを確認する　→

今日はDIY塗装できる日か知りたい

や印工務店は、電子工作、自作PC、DIY・模型を中心に、実際の制作や修理で必要になった道具と記録をまとめている個人の工房です。

一度調べて終わりではなく、次の作業でも使いたいものはWebツールへ。試して分かったことや失敗したことは、制作記録として残しています。

3つの作業台Work benches

3つの作業台

WB-A ／ ELECTRONICS

電子工作

LED、抵抗、配線、はんだ付け、部品の端子。
回路を組む前の計算から、組んだ後の確認まで。

WB-B ／ PC BUILD

自作PC

CPU、メモリ、ストレージ、電源、USB-C。
パーツ選びから組み立て、不調の切り分けまで。

WB-C ／ DIY & MODEL

DIY・模型

接着、ねじ、塗装、材料加工。
何を使うか、いつ作業するか迷ったときの確認に。

この道具箱を作っている理由Why it exists

毎回調べ直すなら、
次に使える形で残す。

計算式は分かった。でもまた計算する。

部品は分かった。でも端子を忘れた。

直った。でも何を確認したか残っていない。

制作や修理をしていると、一度調べたことを数か月後にもう一度調べることがあります。

そんな小さな手間を、計算機や診断ナビ、早見表として少しずつ道具にしています。うまくいかなかった方法も、次の判断に使える情報として残します。
